# Naming Conventions

## Creative Language Mapping

The LocalCircus ecosystem uses theatrical and circus-themed language for better immersion and memorability:

- Workflow → Act
- Workspace → Big Top
- Plugin → Performer
- Install → Adopt
- Repository → Collection
- Model → Animal (Zoo category)
- Developer Tools → Workshop
- Runtime → Ringmaster Core

## Naming Rules

### For creators:
- Artifact name constraints (lowercase, hyphens)
- Max length guidelines (40 chars)

## UI Text Conventions

### Standard phrases:
- "Create" → "Forge" (for artifacts)
- "Delete" → "Release" or "Unadopt"
- "Settings" → "Backstage"
- "Plugins" → "Performers"
