# LocalCircus Brand Guidelines

## Logo & Mark

The LocalCircus brand uses a circus-themed identity featuring a stylized big top with microphone elements. The logo represents the spirit of creativity, performance, and community.

### Logo Usage
- Maintain clear space equivalent to one "stripe" around the logo
- Minimum size: 32px on digital interfaces, 1 inch in print
- Colors must remain consistent - no variants or modifications

### Minimum Sizes
- **Digital**: 16px for icons, 32px for app bars
- **Print**: 1 inch minimum for business materials
- **Large Format**: 3 feet minimum for signage

## Color Palette

### Primary Colors
- **Red Circus**: #FF4444 - Energy, passion, attention-grabbing
- **Blue Big Top**: #4466FF - Stability, trust, professionalism  
- **Yellow Spotlight**: #FFD700 - Success, achievement, optimism

### Secondary Colors
- **Green Trapeze**: #44BB66 - Growth, harmony, nature
- **Purple Evening**: #9944BB - Creativity, imagination, wisdom
- **Orange Popcorn**: #FF8844 - Warmth, friendliness, community

### Accent Colors
- **Coral Performer**: #FF6B6B - Bold, energetic, dynamic
- **Teal Clouds**: #44CCCC - Clear, calm, soothing
- **Yellow Flash**: #FFEE44 - Attention, warning, celebration

### Semantic Colors
- **Success**: #44BB66 (Green Trapeze)
- **Warning**: #FF8844 (Orange Popcorn)
- **Error**: #FF4444 (Red Circus)
- **Info**: #4466FF (Blue Big Top)

### Dark Mode
- **Background**: #1A1A1A
- **Surface**: #2D2D2D
- **Text**: #FFFFFF
- **Primary**: #FF6B6B
- **Secondary**: #44CCCC

## Typography

### Primary Fonts
- **Headings**: "Playfair Display", serif (elegant, circus-inspired)
- **Body Text**: "Inter", system-ui, sans-serif (modern, readable)
- **Code**: "JetBrains Mono", monospace

### Size Scale
- **Display**: 72px (hero sections)
- **H1**: 48px (page titles)
- **H2**: 36px (section headers)
- **H3**: 28px (sub-section headers)
- **H4**: 24px (component titles)
- **Body Large**: 18px (descriptive text)
- **Body Regular**: 16px (main content)
- **Body Small**: 14px (captions, metadata)

## Iconography

### Style
- **Rounded**: Friendly, approachable
- **Outline**: For dark backgrounds
- **Consistent**: 2px stroke weight

### Size Scale
- **XS**: 16px, **S**: 24px, **M**: 32px, **L**: 48px, **XL**: 64px

### Category Icons
- **Model/Animal**: Paw print inside geometric shape (Green)
- **Agent/Performer**: Microphone icon (Blue circle)
- **Workflow/Act**: Stage area with spotlight (Red accent)
- **Tool**: Toolbox (Orange border)
- **Plugin/Performer**: Ribbon or sparkle icon (Purple)
- **Theme**: Color palette (Rainbow gradient)

## Tone of Voice

### Core Principles
- **Friendly and empowering**
- **Clear and direct**
- **Confident but not arrogant**

### UI Text Conventions
| Traditional | LocalCircus |
|-------------|-------------|
| Create | Forge |
| Delete | Release or Unadopt |
| Settings | Backstage |
| Plugins | Performers |
| Install | Adopt |
| Uninstall | Release |

## Status Indicators
- **Active**: Green pulse animation
- **Inactive**: Gray outline
- **Error**: Red exclamation mark
- **Success**: Checkmark with green background
- **Loading**: Circular spinner
