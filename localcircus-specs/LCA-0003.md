# LCA-0003: Artifact Card Specification

**Status:** Draft  
**Version:** 1.0.0  
**Created:** 2024-01-15

## Overview

An Artifact Card is a compact, visual representation of an artifact optimized for display in browsable interfaces like the Local Zoo. It provides at-a-glance information about an artifact without requiring full DNA access.

## Card Structure

```typescript
interface ArtifactCard {
  // Identity (required)
  uuid: string;
  name: string;
  displayName: string;
  type: ArtifactType;
  version: string;
  icon: string;              // Emoji or icon identifier
  
  // Summary
  shortDescription: string;  // Truncated to ~100 chars
  
  // Classification
  category: CategoryInfo;
  tags: string[];            // Top 5 keywords
  
  // Social proof
  rating?: number;           // 1-5 stars
  ratingCount?: number;      // Number of ratings
  downloads?: number;
  
  // State
  installed?: boolean;
  updateAvailable?: boolean;
  latestVersion?: string;
  
  // Trust
  verified?: boolean;
  trustLevel?: 'unverified' | 'verified' | 'trusted' | 'official';
}

interface CategoryInfo {
  id: string;
  name: string;
  icon: string;
  color: string;
}
```

## Rendering Rules

### Text Truncation

| Field | Max Length | Truncation |
|-------|------------|------------|
| `displayName` | 50 chars | Ellipsis |
| `shortDescription` | 100 chars | Ellipsis |
| `tags` | 5 items | Exclude remainder |

## Card Generation

Cards are generated from DNA:

```typescript
function toCard(dna: ArtifactDNA): ArtifactCard {
  return {
    uuid: dna.uuid,
    name: dna.name,
    displayName: dna.displayName || dna.name,
    type: dna.type,
    version: dna.version,
    icon: getTypeIcon(dna.type),
    shortDescription: truncate(dna.metadata.description, 100),
    category: getCategory(dna.type),
    tags: dna.metadata.keywords.slice(0, 5),
    rating: undefined,           // From registry
    downloads: undefined,        // From registry
    installed: false,            // From local state
    updateAvailable: false,       // From local state
    verified: dna.signatures?.creator !== undefined,
    trustLevel: getTrustLevel(dna),
  };
}
```
