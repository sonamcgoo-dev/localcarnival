# LCA-0004: Registry Schema Specification

**Status:** Draft  
**Version:** 1.0.0  
**Created:** 2024-01-15

## Overview

The Registry is the central database for all LocalCircus artifacts. It maintains the artifact graph, relationships, versions, and discovery metadata. The Registry Schema defines how artifacts are stored, indexed, and queried.

## Data Model

### Artifact Entry

```typescript
interface RegistryEntry {
  // Core identity
  uuid: string;               // From DNA
  name: string;               // From DNA
  type: ArtifactType;         // From DNA
  
  // Latest version
  version: string;             // Latest stable version
  versions: VersionEntry[];     // All versions
  
  // Discovery
  displayName: string;
  shortDescription: string;
  icon: string;
  category: string;
  tags: string[];
  
  // Social
  rating: number;              // Average rating (1-5)
  ratingCount: number;           // Number of ratings
  downloads: number;            // Total downloads
  trendingScore: number;         // Computed trending score
  
  // Trust
  trustLevel: TrustLevel;
  publisher: PublisherInfo;
  
  // Timestamps
  createdAt: number;
  updatedAt: number;
  publishedAt: number;
  
  // Relationships
  dependents: string[];          // Artifacts that depend on this
  dependencies: string[];       // Artifacts this depends on
  
  // Metadata
  verified: boolean;
  featured: boolean;
  deprecated: boolean;
  deprecationMessage?: string;
}

interface VersionEntry {
  version: string;
  dna: ArtifactDNA;            // Full DNA for this version
  publishedAt: number;
  changelog?: string;
  downloadUrl?: string;
  checksum?: string;
}

type TrustLevel = 'unverified' | 'verified' | 'trusted' | 'official';

interface PublisherInfo {
  id: string;
  name: string;
  verified: boolean;
  trustScore: number;          // 0-100
}
```

### Capability Index

```typescript
interface CapabilityIndex {
  capabilities: {
    [capabilityId: string]: {
      artifacts: string[];       // UUIDs of artifacts
      versions: {
        [artifactUuid: string]: string[]; // Versions supporting this cap
      };
    };
  };
}
```

### Dependency Graph

```typescript
interface DependencyGraph {
  nodes: {
    [artifactUuid: string]: {
      name: string;
      version: string;
      type: ArtifactType;
    };
  };
  edges: {
    [artifactUuid: string]: {
      dependencies: Array<{
        name: string;
        versionRange: string;
        resolved?: {
          uuid: string;
          version: string;
        };
      }>;
      dependents: string[];     // Artifacts that depend on this
    };
  };
}
```

## Query Parameters

### List Artifacts

```
GET /artifacts
  ?type=agent              // Filter by type
  &category=ai-agents      // Filter by category
  &tag=gpt-4               // Filter by tag
  &search=openai           // Full-text search
  &sort=downloads          // Sort: downloads, rating, updated, name
  &order=desc             // Order: asc, desc
  &page=1                  // Page number
  &limit=20               // Items per page
```

### Search

```
GET /search
  ?q=openai gpt-4          // Search query
  &type=agent              // Optional type filter
  &category=ai-agents      // Optional category filter
  &tags=gpt-4,chat         // Multiple tags (AND)
  &minRating=4             // Minimum rating
  &verified=true           // Only verified publishers
  &limit=10                // Number of results
```

### Resolve Dependencies

```
GET /resolve/my-artifact
  ?version=^1.0.0          // Version constraint
  &registry=local          // Registry to use
```

## Compatibility Checking

The registry maintains a compatibility matrix:

```typescript
interface CompatibilityMatrix {
  artifacts: {
    [artifactUuid: string]: {
      compatible: {
        [platform: string]: {
          [architecture: string]: string[]; // Compatible versions
        };
      };
    };
  };
}
```

### Check Compatibility

```typescript
function checkCompatibility(
  artifact: ArtifactDNA,
  platform: string,
  architecture: string
): boolean {
  const compat = artifact.compatibility;
  
  // Check platform
  if (compat.platforms?.length && !compat.platforms.includes(platform as Platform)) {
    return false;
  }
  
  // Check architecture
  if (compat.architectures?.length && !compat.architectures.includes(architecture as Architecture)) {
    return false;
  }
  
  // Check LocalCircus version
  if (compat.localcircus) {
    const lcVersion = getLocalCircusVersion();
    if (!semverSatisfies(lcVersion, compat.localcircus)) {
      return false;
    }
  }
  
  return true;
}
```

## Recommendation Engine

The registry provides recommendations based on:

1. **Similar artifacts** - Same category/type with overlapping capabilities
2. **Frequently installed together** - Co-installation patterns
3. **Trending** - High recent activity
4. **Dependencies** - Artifacts commonly used together

```typescript
interface Recommendations {
  for: string;              // Artifact UUID
  because: 'similar' | 'installed-with' | 'trending' | 'dependency';
  artifacts: Array<{
    uuid: string;
    score: number;          // Relevance score (0-1)
    reason: string;         // Human-readable reason
  }>;
}
```

## Storage

### Local Registry

For the Local Zoo, registry data is stored in:

```
.localcircus/
├── registry/
│   ├── index.json          // Main index
│   ├── artifacts/
│   │   └── {uuid}.json    // Individual artifact entries
│   ├── capabilities.json   // Capability index
│   ├── graph.json          // Dependency graph
│   └── cache/
│       └── {uuid}.json     // Cached remote data
```
