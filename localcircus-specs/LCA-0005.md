# LCA-0005: Capability Tags Specification

**Status:** Draft  
**Version:** 1.0.0  
**Created:** 2024-01-15

## Overview

Capability Tags define standardized capabilities that artifacts can declare. They enable discovery, compatibility checking, and composition by providing a common vocabulary for what artifacts can do.

## Capability Definition

```typescript
interface CapabilityTag {
  id: string;               // Unique identifier (e.g., "chat")
  name: string;             // Human-readable name
  description: string;      // What this capability means
  version?: string;         // Version of the capability spec
  
  // Relationships
  category: CapabilityCategory;
  parent?: string;          // Parent capability (for hierarchies)
  children?: string[];       // Child capabilities
  
  // Compatibility
  requires?: string[];       // Capabilities this depends on
  conflicts?: string[];      // Capabilities this is incompatible with
  
  // Metadata
  tags?: string[];           // Related keywords
  examples?: string[];       // Example artifacts
}
```

## Capability Categories

```typescript
type CapabilityCategory = 
  | 'ai'           // AI/ML capabilities
  | 'language'      // Language processing
  | 'vision'       // Visual processing
  | 'audio'        // Audio processing

  | 'network'      // Network operations
  | 'security'     // Security features
  | 'integration'  // Third-party integrations

  | 'utility';     // General utilities
```

## Versioning

Capabilities use semver for versioning:

```typescript
interface CapabilityVersion {
  version: string;           // e.g., "1.0.0"
  changes: string[];          // List of changes
  added: CapabilityVersionChange[];
  removed: CapabilityVersionChange[];
  deprecated: CapabilityVersionChange[];
  breaking: boolean;          // Breaking change flag
}
```

### Version Compatibility

| Constraint | Meaning |
|------------|---------|
| `1.0` | Compatible with 1.x |
| `^1.0.0` | Compatible with 1.y.z where y >= 0 |
| `~1.0.0` | Compatible with 1.0.z |
| `>=1.0.0 <2.0.0` | Range of compatible versions |

## Capability Matching

### Exact Match

```typescript
function exactMatch(required: Capability, provided: Capability): boolean {
  return required.id === provided.id && 
         semver.satisfies(provided.version || '*', required.version || '*');
}
```

### Subset Match

```typescript
function subsetMatch(required: Capability[], provided: Capability[]): boolean {
  return required.every(req => 
    provided.some(prov => exactMatch(req, prov))
  );
}
```

## Capability Discovery

### Find by Tag

```typescript
function findByTag(tag: string): CapabilityTag[] {
  return ALL_CAPABILITIES.filter(cap => 
    cap.tags?.includes(tag) ||
    cap.id.includes(tag) ||
    cap.name.toLowerCase().includes(tag.toLowerCase())
  );
}
```

### Find by Category

```typescript
function findByCategory(category: CapabilityCategory): CapabilityTag[] {
  return ALL_CAPABILITIES.filter(cap => cap.category === category);
}
```

### Find Compatible Artifacts

```typescript
function findCompatibleArtifacts(
  requiredCapabilities: Capability[]
): ArtifactDNA[] {
  return allArtifacts.filter(artifact => 
    subsetMatch(requiredCapabilities, artifact.capabilities)
  );
}
```

## Custom Capabilities

Artifacts can define custom capabilities:

```typescript
interface CustomCapability {
  id: string;              // Must be prefixed with namespace
  name: string;
  description: string;
  schema?: JSONSchema;      // Optional schema definition
}

// Example custom capability
{
  "id": "com.myorg.image-generator",
  "name": "MyOrg Image Generator",
  "description": "Generate images using MyOrg's proprietary model",
  "schema": {
    "type": "object",
    "properties": {
      "prompt": { "type": "string" },
      "size": { "type": "string", "enum": ["256", "512", "1024"] }
    },
    "required": ["prompt"]
  }
}
```
