## Specification Format

Each LCA follows a standard format:

```
LCA-XXXX/
├── title.md              # Main specification
├── examples/             # Example implementations
└── references/          # Related specifications
```

## Contributing

To propose a new specification:

1. Create a new LCA file with draft status
2. Include motivation, detailed specification, and examples
3. Submit for review via PR
