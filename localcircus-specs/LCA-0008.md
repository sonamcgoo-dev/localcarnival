# LCA-0008: Plugin Interface Specification

**Status:** Draft  
**Version:** 1.0.0  
**Created:** 2024-01-15

## Overview

Plugins (called "Performers" in LocalCircus) extend the functionality of the platform. They are loaded at runtime and can contribute UI components, commands, capabilities, and integrations.

## Plugin Structure

```
my-plugin/
├── plugin.json              # Plugin manifest
├── plugin.lcadna            # Plugin DNA
├── dist/                    # Compiled code
│   ├── index.js             # Entry point
│   └── ...                  # Other modules
├── ui/                      # UI components (optional)
│   └── components/
└── README.md                # Documentation
```

## Plugin Manifest

```typescript
interface PluginManifest {
  // Identity
  id: string;                // Unique plugin ID
  name: string;              // Display name
  version: string;           // Semver version
  
  // LocalCircus
  localcircus: {
    minVersion: string;      // Minimum LocalCircus version
    maxVersion?: string;     // Maximum LocalCircus version
  };
  
  // Entry
  main: string;              // Entry file (relative to manifest)
  
  // Capabilities
  capabilities: string[];    // Capability IDs this plugin provides
  
  // Permissions
  permissions: Permission[];
  
  // UI (optional)
  ui?: {
    panels?: PanelDefinition[];
    commands?: CommandDefinition[];
    shortcuts?: ShortcutDefinition[];
  };
  
  // Dependencies
  dependencies: PluginDependency[];
}

interface Permission {
  type: PermissionType;
  description: string;
}

type PermissionType = 
  | 'filesystem:read'
  | 'filesystem:write'
  | 'network:http'
  | 'network:webhook'
  | 'storage:read'
  | 'storage:write'
  | 'ai:chat'
  | 'ai:embeddings'
  | 'exec'
  | 'secrets:read'
  | 'secrets:write';
```

## Plugin Interface

```typescript
interface LocalCircusPlugin {
  // Lifecycle
  onLoad(context: PluginContext): void | Promise<void>;
  onUnload(): void | Promise<void>;
  
  // Optional lifecycle
  onInstall?(): void | Promise<void>;
  onUpdate?(oldVersion: string): void | Promise<void>;
  onEnable?(): void | Promise<void>;
  onDisable?(): void | Promise<void>;
}

interface PluginContext {
  // Plugin info
  plugin: {
    id: string;
    name: string;
    version: string;
  };
  
  // Core services
  core: RingmasterCore;
  storage: LocalStorage;
  eventBus: EventBus;
  
  // Utilities
  logger: Logger;
  config: ConfigStore;
  secrets: SecretsManager;
  
  // AI
  providers: ProviderManager;
  models: ModelManager;
  
  // UI
  ui?: UIRuntime;
}

interface Logger {
  debug(message: string, ...args: any[]): void;
  info(message: string, ...args: any[]): void;
  warn(message: string, ...args: any[]): void;
  error(message: string, ...args: any[]): void;
}
```

## Entry Point

The plugin entry point must export a default or named export:

```typescript
// Default export
export default new MyPlugin();

// Named export
export const plugin = new MyPlugin();

// Factory function
export function createPlugin(): LocalCircusPlugin {
  return new MyPlugin();
}
```

## Example Plugin

```typescript
import type { LocalCircusPlugin, PluginContext } from '@localcircus/core';

class MyPlugin implements LocalCircusPlugin {
  private context?: PluginContext;
  
  async onLoad(context: PluginContext): Promise<void> {
    this.context = context;
    
    // Register command
    context.core.registerCommand({
      id: 'my-plugin.greet',
      name: 'Greet',
      description: 'Say hello',
      execute: this.greet.bind(this),
    });
    
    // Subscribe to events
    context.eventBus.on('user:login', this.onUserLogin.bind(this));
    
    // Log
    context.logger.info('MyPlugin loaded');
  }
  
  async onUnload(): Promise<void> {
    // Cleanup
    context.logger.info('MyPlugin unloaded');
  }
  
  private async greet(args: { name: string }): Promise<string> {
    return `Hello, ${args.name}!`;
  }
  
  private async onUserLogin(event: any): Promise<void> {
    context.logger.info(`User logged in: ${event.username}`);
  }
}

export default new MyPlugin();
```

## UI Components

### Panel

```typescript
interface PanelDefinition {
  id: string;
  title: string;
  icon?: string;
  component: string;        // Component name
  location: 'left' | 'right' | 'bottom' | 'floating';
  size?: { width?: number; height?: number };
  minSize?: { width: number; height: number };
  maxSize?: { width: number; height: number };
}

// In plugin
context.ui?.registerPanel({
  id: 'my-plugin.panel',
  title: 'My Panel',
  icon: '📊',
  component: 'MyPanelComponent',
  location: 'right',
  size: { width: 300 },
});
```

### Command

```typescript
interface CommandDefinition {
  id: string;
  name: string;
  description?: string;
  icon?: string;
  shortcut?: string;        // e.g., "Ctrl+K"
  args?: CommandArg[];
}

interface CommandArg {
  name: string;
  type: 'string' | 'number' | 'boolean' | 'select';
  description?: string;
  required?: boolean;
  default?: any;
  options?: { label: string; value: any }[];
}

// In plugin
context.ui?.registerCommand({
  id: 'my-plugin.search',
  name: 'Search',
  icon: '🔍',
  shortcut: 'Ctrl+K',
  args: [
    { name: 'query', type: 'string', required: true }
  ],
});
```

### Shortcut

```typescript
interface ShortcutDefinition {
  id: string;
  keys: string;             // e.g., "Ctrl+Shift+P"
  description: string;
  action: string;          // Command ID or action name
}

// In plugin
context.ui?.registerShortcut({
  id: 'my-plugin.toggle',
  keys: 'Ctrl+Shift+T',
  description: 'Toggle my feature',
  action: 'my-plugin.toggle',
});
```

## Storage

Plugins have access to persistent storage:

```typescript
// Read
const data = await context.storage.read('my-key');

// Write
await context.storage.write('my-key', { foo: 'bar' });

// Delete
await context.storage.delete('my-key');

// List keys
const keys = await context.storage.list('prefix:');

// File storage
await context.storage.writeFile('path/to/file.txt', 'content');
const content = await context.storage.readFile('path/to/file.txt');
```

## Configuration

```typescript
// Get config
const config = context.config.get('my-setting');

// Set config
context.config.set('my-setting', 'value');

// Subscribe to changes
context.config.onChange('my-setting', (newValue, oldValue) => {
  // Handle change
});
```

## Secrets

```typescript
// Read secret (requires permission)
const apiKey = await context.secrets.get('MY_API_KEY');

// Write secret (requires permission)
await context.secrets.set('MY_API_KEY', 'secret-value');

// Delete secret
await context.secrets.delete('MY_API_KEY');
```

## Event Bus

```typescript
// Subscribe
const unsubscribe = context.eventBus.on('some:event', (data) => {
  // Handle event
});

// Unsubscribe
unsubscribe();

// Emit
context.eventBus.emit('my:event', { foo: 'bar' });

// Once
context.eventBus.once('my:event', (data) => {
  // Handle once
});
```

## Loading Plugins

### From Directory

```typescript
const runtime = new PluginRuntime(core, storage);
await runtime.loadFromDirectory('/path/to/plugins');
```

### From Package

```typescript
await runtime.load('my-plugin');
```

### Dynamic Loading

```typescript
const plugin = await runtime.loadDynamic(code, {
  id: 'dynamic-plugin',
  name: 'Dynamic Plugin',
  version: '1.0.0',
});
```

## Lifecycle

```
┌─────────┐     ┌──────────┐     ┌─────────┐
│ Installed │ ──> │  Loaded  │ ──> │ Enabled │
└─────────┘     └──────────┘     └─────────┘
                     │                  │
                     │                  │
                     v                  v
              ┌──────────┐       ┌─────────┐
              │ Unloaded │ <──── │Disabled │
              └──────────┘       └─────────┘
```

| State | Description |
|-------|-------------|
| `installed` | Plugin files are present |
| `loaded` | Plugin code is initialized |
| `enabled` | Plugin is actively running |
| `disabled` | Plugin is temporarily disabled |
| `unloaded` | Plugin is not in memory |

## Security

### Permissions

Plugins declare required permissions in manifest:

```json
{
  "permissions": [
    { "type": "filesystem:read", "description": "Read configuration files" },
    { "type": "network:http", "description": "Fetch remote resources" }
  ]
}
```

### Sandboxing

Plugins run in a sandboxed environment:

- No direct system access
- Network access through controlled APIs
- File access limited to plugin directory
- No access to other plugins' data

### Verification

Plugins can be signed:

```typescript
const verified = await runtime.verifySignature(pluginId);
if (!verified) {
  console.warn('Plugin signature not verified');
}
```
