# LocalCircus Roadmap

> Where we've been and where we're going.

## Status Summary

**Current Phase:** Design Documentation Complete ✅

The LocalCircus design documentation is now complete. The following roadmap outlines the path from design to implementation.

---

## Vision

> Technology should disappear behind creation.

LocalCircus is a local-first creative operating environment that amplifies human capability through intelligent tools, automation, and collaboration.

## Technical Priorities

### 1. Developer Experience
- Clean SDKs with great TypeScript types
- Comprehensive documentation
- Working examples
- Fast iteration cycles

### 2. Extensibility
- Plugin system first-class
- MCP and ACP support
- Open standards

### 3. Local-First
- Works offline
- Data stays local
- No vendor lock-in

### 4. Performance
- Fast startup
- Efficient resource use
- Responsive UI
